# wethefit.com

The public website for the WETHEFIT app: landing page, Privacy Policy, Terms & Community Guidelines, and the
account-deletion page the app stores require. Plain HTML, hosted on GitHub Pages at https://wethefit.com.

Pages: `index.html`, `privacy.html`, `terms.html`, `delete-account.html`. Shared styles in `style.css`.
GitHub Pages serves `privacy.html` at `/privacy` as well as `/privacy.html`.

To change a page, edit the HTML and push to `main`; the site updates within a minute or two.
